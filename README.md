Crie um novo projeto com a estrutura do Verdão Prize Wheel: funil com quiz inicial temático do Palmeiras/Verdão, seguido de uma roleta com 5 prêmios e 1 opção de 'tente novamente', animações de giro e fluxo de premiação.
